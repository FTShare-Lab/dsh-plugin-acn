# 已知限制

本文记录当前的使用边界和未完成验证的场景。日常操作见[使用指南](user_guide.md)，完整参数见[配置参考](config.md)。

## 配置与会话

插件设置和会话控件依赖 DSH 的配置、模型、会话及工作区服务；仅加载核心组件的最小 CLI 环境不提供这些界面。宿主缺少凭据托管服务时，插件设置无法保存新密钥，仍可临时检查连接或沿用已有引用；替代方式见[高级配置](config.md#凭据托管不可用时的高级配置)。

「检查连接」反映本次检查结果，保存配置也不保证服务持续可达。后续连接故障可通过 `/acn-status` 和失败任务查看。

会话开始后固定工作配置、Agent ID、知识目录和私有快照，已有历史及无法验证父身份的派生会话不能改绑。更换身份或知识目录后需要新建会话；原数据保留，但不会自动搬移。运行中的实例沿用启动时的连接，新启动或冷恢复实例采用原 upstream 当前保存的团队地址与凭据。更换地址会保留待投队列，符合条件的旧记录可能发往新服务；连接不同团队应新建工作配置。

新会话的项目配置预选依赖可读取的 DSH 会话记录。最近会话的归属无法确认或配置已失效时，回退全局默认；已有会话的绑定失效时，需要恢复原配置。宿主接口与支持平台见 [DSH 兼容边界](dsh-compat.md)。

## 团队仲裁与信息边界

当前建议 Router 使用词法检索，不启用 LLM 重排。ACN Maintainer 采纳前会重新检索并检查输入指纹；Router 缓存刷新、新上传或成员修订引起候选及争议变化时，即使关闭模型重排，也可能进入重分析退避，这是服务的并发保护。模型重排还可能使相同查询重复产生变化，连续变化时停止自动采纳、等待人工处理。这是参考服务之间的联动限制，插件不修改服务端仲裁逻辑。Embedding 检索尚未纳入当前兼容验证范围。

`consult_router` 返回可引用的候选 Claim、关联争议和已解决争议 ID，但不提供完整 Resolution、仲裁内部阶段或 `retrieval_debug`。需要裁决全文或检索降级原因时，应查看对应服务的管理接口和诊断记录。

Maintainer 的属性更新是建议，成员内化后才决定如何修改本地知识，不保证所有成员立即得到相同正文。单人期间修改过的待上传版本会暂停；切回团队后不会自动发布这些变化，需核对当前版本或执行受复核的整合重绑。

自动仲裁的属性更新发送给直接涉争 Claim 的持有者，并非向所有成员广播。其他成员通过 Router 检索最新 Claim 与已解决争议；已有会话的冻结目录不会因此整体重建。

## 知识质量

Claim 可引用、结构合法、能够恢复，不等于结论完整或正确。形成、共享与复用仍可能扩大适用范围、遗漏版本条件，或把临时要求泛化为长期规则。待业务方确认的决策应保留为未决事项，不能仅凭可复现的代码现象写成强制要求。

知识复用依赖 Agent 主动检索和判断。本项目没有提供系统性的自动召回率、事实正确率或节省工时指标。测试与模型自评不能取代对当前代码、证据和业务约定的核对。

## Dream 整理与查证

Dream 使用有界候选上下文，按更新时间装入知识，并在报告中标明遗漏数量；不保证多次运行一定遍历到全部旧知识。模型可能输出不合法的草稿或复核参数；工具会返回错误供其在当前会话内修复，修复也消耗模型轮数。探索额度耗尽后进行有限收尾并结束；收尾仍未完成的事项明确记为未完成，下次触发从当前 Claim 重新开始。

宿主明确报告工具参数 JSON 语法错误时，通过宿主上下文在重试前回喂解析错误和未执行说明，每次子会话最多额外自动重试两次，每次仍消耗原有额度；耗尽后保留进度并显示具体错误分类。此恢复仅覆盖明确的工具输入解析错误，其他响应、网络和鉴权错误沿用宿主处理，不自动修补 JSON 或切换模型。

后台模型默认输出上限为 32768 token，显式配置仍优先。新 Dream 使用原版的简洁逐 Claim 语义复核，不再生成双向全文引用；复杂知识仍可能耗尽上下文或轮数预算。预算上限控制成本，不保证模型判断正确。

整合通过逐 Claim 语义复核说明信息去向，并独立校验来源与承接关系；不要求逐字复制原证据摘要，也不能证明事实相关性或语义等价。已进入 prepared 阶段的固定提交按原恢复协议完成，不追溯重写已经生效的结果。

文件证据校准默认关闭，只提供受限的 `file_read`、`file_grep`、`file_glob` 和只读知识查询，不提供联网检索或命令执行。只有带版本的实际文件读取可以授权事实修改；原始 high Claim 不进入校准。材料本身仍可能错误、恶意或与断言无关。

搜索和读取共用查证预算。宽泛搜索可能在读取目标文件前耗尽文件数或字节数；只有定位结果、没有实际读取回执时，Dream 会保留原判断和置信度，不能视为校准成功。应检查逐组报告，并优先提供明确的项目路径和证据范围。

凭据保护按常见文件名和目录名拦截，不扫描任意文件正文中的秘密，也不构成操作系统沙箱。完整规则见[Dream 证据校准](command-reference.md#dream-证据校准)。

## Memory 的保护范围

Memory 的内容选择仍依赖模型判断。提示词要求保存稳定经验、合并重复内容，并舍弃临时状态与容易重新查询的信息，但 review 仍可能保存冗余的工具用法或过度概括；操作通过校验不等于内容值得长期保存。

自动 review 按已完成的人工轮次触发。`maxTranscriptChars` 限制输入大小，优先删减工具轨迹，再裁剪较旧对话；最近用户与助手正文各保留有界片段，避免长工具输出导致漏触发。裁剪仍可能丢失上下文，`omitted` 会标明输入不完整；触发成功不保证模型有值得保存的内容。

路径保护覆盖已接入的文件工具最终门禁和写入、编辑意图，不限制任意 shell、Node 直接 I/O 或自定义工具，也不提供跨 provider 或操作系统的路径竞争沙箱。当前文件适配基于同机 fs-local，远端共享挂载隔离尚未验证。Windows 的符号链接与目录 junction 会被拒绝，读取前后也校验普通文件、链接数和文件身份；该检查不依赖 `O_NOFOLLOW`，但仍不是抵御其他进程任意改写路径的操作系统沙箱。`0600` 在 Windows 上不提供 POSIX 式的用户隔离，应使用当前用户独占且 ACL 正确的本地目录。UNC、云同步盘及特殊 reparse point 的存储语义未完成实机验证。

私有正文不会被自动知识形成和团队流程直接读取；如果普通助手主动复述私有事实，后续对话投影仍可能看到这些文字。安全扫描与提示词不能证明语义上绝不泄漏。review 会把私有快照交给已配置的模型提供商；“私有”指 Agent 数据与团队知识隔离，不表示离线运行。

## 会话投影与恢复边界

复盘的跨进程修复依赖原 DSH 会话日志仍可读取且归属一致；它无法恢复宿主本身从未保存的事件，也不自动修复正文冲突或跳过超限输入。单条投影限制为 50MiB，多个较小未处理事件可以分片保存。界面中的“未调用知识模型”指本次输入准备失败发生在模型请求前，不代表该任务之前从未尝试过模型调用。

文件占用和原子替换故障已有注入测试，macOS 已进行安装及真实会话验收。Windows 桌面仍缺少实机验收，自动化覆盖范围见[兼容说明](dsh-compat.md#操作系统)。

## 时间与运行状态兼容

UTC 规范年份只接受 0–9999。参考 ACN `0.3.3` 能将部分 offset 时间格式化为四位年份之外的值，但无法再按自身 RFC 3339 规则读回；插件拒绝这类输入，以免写出不可回读的数据。

Dream、形成、Inbox effect、Memory review、会话状态和权限清单属于插件运行时格式。Rust 的 pending checkpoint 或 safety review 缺少插件授权清单，不能直接接管；DTO 读回兼容不意味着运行日志可互换。不要与原生 ACN 共用活动数据目录，迁移时使用[只读导入](command-reference.md#从已有-acn-目录导入)。
