# 已知限制

## 配置与会话

网页模型选择针对 ACN 后台任务，聊天模型仍由 DSH 选择。团队凭据通过宿主环境变量提供，页面只保存变量名。保存成功代表配置已落盘并激活，不代表团队服务一定可达；连接状态和实际请求结果需通过 `/acn-status` 与工具调用确认。

切换 Agent ID 或知识目录后必须新建会话，旧会话及无法验证父身份的历史派生会话不能改绑。身份绑定保存在宿主持久日志中，离线修改 YAML 也不能绕过该限制。原知识不会迁移或删除；只改模型或连接参数时，已有会话继续使用原冻结快照。

配置页依赖 DSH 的 ConfigEditor、Gateway、模型及插件管理客户端服务，终端最小组合不显示网页表单。兼容范围见 [DSH 兼容边界](dsh-compat.md)。

## 团队仲裁与信息边界

当前建议 Router 使用词法检索，不启用 LLM 重排。模型重排可能让相同查询的候选集合变化；ACN Maintainer 采纳前会重新检索并检查输入指纹，因此可能把变化视为需要重新分析，连续变化时停止自动采纳、等待人工处理。这是参考服务之间的联动限制，插件不修改服务端仲裁逻辑。Embedding 检索尚未纳入当前兼容验证范围。

`consult_router` 返回可引用的候选 Claim、关联争议和已解决争议 ID，但不提供完整 Resolution、仲裁内部阶段或 `retrieval_debug`。需要裁决全文或检索降级原因时，应查看对应服务的管理接口和诊断记录。

Maintainer 的属性更新是建议，成员内化后才决定如何修改本地知识，不保证所有成员立即得到相同正文。单人期间修改过的待上传版本会暂停；切回团队后不会自动发布这些变化，需核对当前版本或执行受复核的整合重绑。

## 知识质量与工具反馈

Claim 可引用、结构合法、能够恢复，不等于结论完整或正确。形成、共享与复用仍可能扩大适用范围、遗漏版本条件，或把临时要求泛化为长期规则。待业务方确认的决策应保留为未决事项，不能仅凭可复现的代码现象写成强制要求。

知识复用依赖 Agent 主动检索和判断。本项目没有提供系统性的自动召回率、事实正确率或节省工时指标。测试与模型自评不能取代对当前代码、证据和业务约定的核对。

部分工具参数错误只返回通用校验失败；例如 Claim 更新需要 `expected_revision`，不能写成 `revision`。排查时应对照[工具参数](command-reference.md)，不要反复提交相同的无效输入。

## Dream 整理与查证

Dream 使用有界候选上下文，按更新时间装入知识，并在报告中标明遗漏数量；不保证多次运行一定遍历到全部旧知识。模型可能输出不合法的草稿或复核结果，达到重试上限后任务保留为失败，需修正原因后重试。

整合要求逐字保留原证据摘要、来源及承接关系，但这些检查不能证明事实相关性或语义等价。已进入 prepared 阶段的固定提交按原恢复协议完成，不追溯重写已经生效的结果。

文件证据校准默认关闭，只提供受限的 `read`、`grep`、`glob` 和只读 Claim 查询，不暴露 Web 或命令。只有带版本的实际文件读取可以授权事实修改；原始 high Claim 不进入校准。材料本身仍可能错误、恶意或与断言无关。

凭据保护按常见文件名和目录名拦截，不扫描任意文件正文中的秘密，也不构成操作系统沙箱。完整规则见[Dream 证据校准](command-reference.md#dream-证据校准)。

## Memory 的保护范围

自动 review 需要有界窗口内同时保留用户与助手条目。长编码回合可能让工具轨迹占满 `maxTranscriptChars`，挤出用户条目；即使达到 `intervalTurns`，也不一定创建 review 任务。显式 `memory` 工具和冻结快照不受这一触发条件影响。

路径保护覆盖已接入的文件工具最终门禁和写入、编辑意图，不限制任意 shell、Node 直接 I/O 或自定义工具，也不提供跨 provider 或操作系统的路径竞争沙箱。当前文件适配基于同机 fs-local，远端共享挂载隔离尚未验证。

私有正文不会被自动知识形成和团队流程直接读取；如果普通助手主动复述私有事实，后续对话投影仍可能看到这些文字。安全扫描与提示词不能证明语义上绝不泄漏。review 会把私有快照交给已配置的模型提供商；“私有”指 Agent 数据与团队知识隔离，不表示离线运行。

## 时间与运行状态兼容

UTC 规范年份只接受 0–9999。参考 ACN `0.3.3` 能将部分 offset 时间格式化为四位年份之外的值，但无法再按自身 RFC 3339 规则读回；插件拒绝这类输入，以免写出不可回读的数据。

Dream、形成、Inbox effect、Memory review、会话状态和权限清单属于插件运行时格式。Rust 的 pending checkpoint 或 safety review 缺少插件授权清单，不能直接接管；DTO 读回兼容不意味着运行日志可互换。不要与原生 ACN 共用活动数据目录，迁移时使用[只读导入](command-reference.md#从已有-acn-目录导入)。
