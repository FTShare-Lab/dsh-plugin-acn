# 公开资料清理与验证

日期：2026-10-26。版本 `0.1.0` 未发布。本轮保留公司版权署名，清理公开资料中的个人身份和本机环境信息，并按维护者要求重新初始化 Git。

## 清理范围

- 许可证中的公司名称原样保留。文档保留真实模型名称、验收结论与限制，省略本机供应端别名。
- 用户指南的安装入口、身份、模型及团队连接共四张截图，在新的隔离 DSH 中直接重新采集。只截取必要界面区域，不显示实际数据路径；未通过改写页面或生成模拟 UI 制作截图。
- 删除七张带本机路径或供应端别名的旧截图及相应引用。保留经过检查的团队结果图，明确其来源和验收范围。
- 真实 Web 验收脚本要求显式设置 `ACN_ACCEPTANCE_PROVIDER`，隔离宿主使用中性别名 `acceptance-provider`。凭据仍来自本机配置并只传入子进程环境，日常 profile 不变。
- 安全扫描增加文本邮箱、用户级临时目录及可达提交邮箱检查，补充规则回归。旧历史在清理前被新增邮箱检查拒绝，重新初始化后通过。
- 清除旧安装包，重新构建公开资料。新的 Git 历史使用 `ACN contributors` 署名和空邮箱，不保留旧提交、分支、reflog 或历史备份。

## 网页复验

使用 DSH `0.2.1-rc.2`、独立 DSH_HOME、知识根和合成 Retry lab 项目，模型为 `deepseek-v4-flash-api`。

1. 在网页输入本地 tarball，安装后立即启用 ACN。
2. 保存 `personal`、独立知识目录、指定后台模型与单人模式，页面显示保存并应用成功。
3. 填写未保存的团队示例，采集仅含配置控件的截图，再重新加载；确认恢复单人模式，没有保存示例 endpoint。
4. 真实模型通过文件工具读取示例契约，区分幂等读取、显式预算、写入的独立幂等校验，以及文件没有规定的数值与实现。
5. Finalize 首次尝试成功，但本次短会话没有新增 Claim。没有把任务成功写成产生了知识，也没有将这轮截图当作新的团队联通证据。

知识结果展示沿用已完成的[真实团队验收](2026-10-23-model-team-loop.md)，原图不包含个人路径、邮箱或供应端别名。`claim` 工具只查询和修订已有知识，新条目通过 Recap / Finalize 形成；本轮没有修改该边界。
